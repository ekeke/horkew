# 狼譜（howl）チートシート — 進行の書き方

mirurou の狼譜エディタで **進行（その日その日の出来事）** を書くための早見表です。

> **エディタが書くのは「進行」だけ**
> 役職構成・ルール・参加者（席）は、エディタの外のフォームで設定済みです。
> 本文には `setup:` や `+ 名前` の行を書く必要はありません（保存時に自動で焼き込まれます）。
> このページに出てくるのは、**日々の進行で書く行だけ**です。

---

## 基本ルール

- **1 行 = 1 つの出来事**。上から時系列に並べます。
- **空行は自由**。読みやすさのために入れて構いません（無視されます）。
- **名前はゆるく一致**します。席で設定した表示名・短縮名・あだ名のどれで書いても OK。ひらがな／カタカナの違い、先頭一致・部分一致も吸収されます（例: `神代美耶子` を `美耶子` や `みやこ` と書いても通る）。
- **矢印はどれでも OK**: `→` `⇒` `->` `=>`（全角 `＝＞` 等も可）。
- **日付は自動で進みます**。`襲撃`／`平和` を書くと「その夜が明けて翌日へ」進みます。区切りを目で見せたいときだけ、後述の `2日目:` を書けます（任意）。

---

## CO・占い／霊媒の結果

| 書きたいこと | 書き方の例 |
| --- | --- |
| 占い CO（結果つき） | `アリス 占いCO ボブ ○` |
| 占い CO（黒結果） | `アリス 占いCO ボブ ●` |
| 結果だけ（2 日目以降） | `アリス ボブ ○` |
| 霊媒 CO | `志村 霊媒CO` |
| 霊媒の結果だけ | `志村 ○`（対象は前夜の処刑者を自動補完） |
| 共有 CO（2 人まとめて） | `共有 三上 高遠` |
| 狩人 CO（護衛先つき） | `エミリ 狩人CO アリス` |
| 素村 CO（村人宣言） | `須田 村人CO` |
| 占い予告 | `アリス 予告 フランク` |

- **白判定**: `○` `◯` `〇` `白`／**黒判定**: `●` `黒`／**子狐**: `子狐`
- CO は **役職名 + `CO`** で書きます（`占いCO` `占い師CO` `霊媒CO` `狩人CO` `村人CO` …）。役職名の表記ゆれは下の[役職早見表](#役職の呼び名早見表)を参照。

## 投票

| 書きたいこと | 書き方の例 |
| --- | --- |
| 単独投票 | `アリス → ボブ` |
| 複数人が同じ相手へ | `[アリス,ボブ] → エミリ` |
| グレラン（指定なし一斉投票）の宣言 | `グレラン` |
| 再投票（決選）の宣言 | `再投票` または `---` または `===` |

---

## 昼と夜の結果

| 出来事 | 書き方の例 |
| --- | --- |
| 処刑（昼の死亡） | `アリス 処刑`（`処刑 アリス` も可） |
| 処刑なし（処刑が行われない） | `処刑なし` |
| 襲撃（夜の死亡） | `ボブ 襲撃`（`ボブ 死亡` / `死亡 ボブ` も可） |
| 平和（護衛成功＝夜の死者なし） | `平和` |
| 道連れ（猫又） | `村１ 道連れ` |
| 後追い（背徳者） | `フランク 後追い` |
| 突然死 | `アリス 突然死` |

> `襲撃` と `平和` は「夜が明けた」合図でもあり、次の日へ進みます。

## 日付の区切り（任意）

進行は自動で日が進むので普段は不要ですが、見やすさのために明示できます。
**末尾のコロン（`:` / `：`）が必須**です。

```
2日目:
Day 2:
```

- 現在より前の日や、1 日以上飛ばした日を指定するとエラーになります（連続する日だけ）。

## ゲームの終了と役職開示

| 書きたいこと | 書き方の例 |
| --- | --- |
| 村勝ち | `村勝`（`村陣営勝利` なども可） |
| 人狼勝ち | `狼勝` |
| 妖狐勝ち | `狐勝` |
| 引き分け | `引分` |
| 役職の開示（エンディング・任意） | `アリス=人狼` |

役職開示は、結末の後に「実は誰が何だったか」を見せたいときに `名前=役職` で書きます。

## セリフ（発言を載せる）

プレイヤーの発言をそのまま書き起こしたいときは、**`名前 ＞ 発言`** の形で書きます。

```
アリス ＞ 占いCO ボブは白でした
ボブ ＞ えっ、それ偽でしょ
```

- 矢印は **`＞`（全角）または `>`（半角）**。投票の `→`（または `->` `=>`）とは別物です。
- 発言の中身は自由（記号・絵文字も可）。行の頭は必ず「名前 ＞」。

---

## 特殊ルール（使うときだけ）

特定のレギュレーションでだけ使う記法です。普通の村では不要。

| 出来事 | 書き方の例 |
| --- | --- |
| 公式アナウンス（GM が役職を公示。例: 契約者ペアの公開） | `※ アリス 契約者`（`GM: アリス 契約者` も可） |
| 死体で発見（契約者の焔薙など、公開された強制退場） | `アリス 死体で発見` |

## メモとネタバレ

| 書きたいこと | 書き方 |
| --- | --- |
| ただのメモ（解析に影響しない） | `# ここはコメント。行頭が # なら無視されます` |
| 視点メモ（解析の仮定として効かせる） | `!アリス=人狼` |

- `#` で始まる行は **コメント**。自由なメモを残せます。
- `!名前=役職`（または `!名前=狼陣営` 等）は **spoiler（仮定）**。「この人はこの役職／陣営だ」と仮定して推理を効かせたいときに使います。間違った仮定を置くと推理が矛盾するので注意。

## 動画と同期させる

再生位置と進行行を結びつけたいとき（観戦動画つき投稿）に使います。

| 書きたいこと | 書き方 |
| --- | --- |
| この行の再生位置 | 行末に `@1:23`（`@分:秒`。1 時間超は `@1:02:03`） |
| 2 本目以降の動画を切り替え | `@https://www.youtube.com/watch?v=...` |

- 1 本目の動画は投稿フォームの「代表動画 URL」で設定するので、本文では `@分:秒` を書くだけで同期します。
- 2 本目以降に切り替えるときだけ `@URL` の行を置き、その後の `@分:秒` はその動画基準になります。

## まるごと例

席（参加者）と構成はフォームで設定済みとして、本文（進行）はこう書きます。

```
# 1日目
アリス 占いCO ボブ ○
チャーリー 占いCO ダン ○
志村 霊媒CO

グレラン
アリス → エミリ
ボブ → エミリ
[チャーリー,ダン] → エミリ
エミリ → アリス

エミリ 処刑

# アリスが翌晩の占い先を予告
アリス 予告 フランク

# 夜：狼がアリスを襲撃（→ 2日目へ）
アリス 襲撃

2日目:
チャーリー フランク ●
志村 ○

チャーリー → フランク
フランク → チャーリー

フランク 処刑
ボブ 襲撃

村勝

# エンディング（任意）
アリス=占い師
フランク=人狼
```
