# NAME

Howl - Horkew OutLine Log

人狼ゲームのゲーム展開の記録言語

第三者視点からの観戦記録を取りやすくすることを主眼とする。

# 言語仕様

行単位で各種結果を記入していくだけ。ただし、以下の例外規則がある

 - エントリー記法`+`は巻き上げられ最初に処理される

## 利用可能な文字

速記性を重視し、IMEを切り替える必要がないよう各種記号や英数字は可能な限り全角でも有効となる

## 記述可能な内容

### entry

`+`ではじまる行で、プレイヤーの参加を宣言できる。区切り文字（`/`,`,`）をつかい一行に複数のプレイヤーを記述可能。
プレイヤー名を指定して以降、記述内でそのプレイヤー名を使用できる。
記述を簡便に行えるよう、プレイヤーを一意に特定できる範囲で省略した書き方が許される。ひらがな、カタカナの違いなど可能な限り無視される。

処理系は以下の優先順位でプレイヤーの特定を行う
 1. 先頭から一意に一致　（「二郎三郎」と「裕二郎」に対して「二郎」で検索した場合、二郎三郎を一意一致とする)
 2. プレイヤー名中で部分一致で一意
 3. (２文字指定の場合のみ)中一文字省略とみなした部分一致検索

### 投票

右矢印(`→`,`->`,`=>`)を含む行は通常投票を示す。投票者→被投票者

左矢印（`←`,`<-`,`<=`）を含む行は決選投票を表す。被投票者←投票者、投票者…

区切り行（`----`）で投票ラウンドの区切りを指定できる。投票状況はリセットされる。
通常投票記法と決選投票記法は混在させることはできない。記法が変わった場合、区切りがあったものとみなされ投票ラウンドが更新される。

### ゲーム処理

ゲーム処理名（処刑、殺害など）から始まり、コマンド区切り文字を挟んで対象プレイヤーを記述することでゲーム処理が行われたことを記述できる。

処理対象が１名の場合、区切り文字は省略できる。また転置してもよい。

### プレイヤー行動

プレイヤー名から始まり、コマンド区切り文字（コロン`:`または空白` `）を挟んでプレイヤーの行動を記述する。コマンド区切り文字を利用して複数の行動を記述できる。

行動は以下に分類される

#### CO

役職名＋COでプレイヤーが自らの役職を明かしたことを記述できる

#### 証言

自らの行動結果を証言した場合の記法。行動タイミング、行動対象、行動結果をそれぞれ記述できるが、具体的な行動内容自体はコンテキストによって解釈され、記法自体には含まれない。

##### 複数証言の列記と行動タイミング

行動結果は基本的に前日の行動結果とみなされる。
三日目の`占い太郎 山本○`は二日目の行動結果と解釈される。一行に複数の行動結果がある場合、右から左に結果数分繰り下げた日の行動結果と解釈される。

```
# 三日目のCO
ハイラム：　占いCO　マドック白　メイソン黒
# 一日目の夜にマドック占い、二日目の夜にメイソン占いと解釈される。（０日目（お告げ）は不明となる。）
```


### 終了記法

陣営名＋勝利の行でゲームの終了を宣言できる。
