
# Howl (Horkew OutLine Log)

**Howl** は人狼ゲームの展開を第三者視点で速記するためのシンプルな記述言語です。ゲーム記録の標準化と記録・共有を容易にすることを目的としています。

## 特徴

- シンプルな記法で速記が可能
- IMEの切り替えが最小限になるよう設計
- 曖昧なプレイヤー名特定機能
- コメントやネタバレ(Spoiler)コメントに対応

## クイックスタート

### 記法の基本例

```howl
+太郎, 花子, 次郎

太郎→花子
花子→次郎
----
処刑: 花子
次郎: 占いCO 太郎○

村人陣営勝利
```

## 記法詳細

### フロントマター

ファイル冒頭にメタ情報をYAML形式で記述可能です。

```yaml
---
date: 2025-03-29
location: Discord
event: オンライン人狼会
players: 10
---
```

### エントリー記法

`+`でプレイヤー参加を宣言します。

```howl
+太郎, 花子, 次郎
```

複数のエントリー記法は最初にまとめて処理されます。

### 投票記法

通常投票（投票者→対象者）：

```howl
太郎→花子
```

決選投票（対象者←投票者）：

```howl
花子← 太郎 次郎
```

`----` で投票ラウンドを区切ります。

### ゲーム処理記法

ゲーム処理（処刑、殺害など）を記述します。

```howl
処刑: 花子
殺害 次郎
```

### プレイヤー行動記法

プレイヤーの行動は名前＋`:`または空白区切りで記述します。

```howl
太郎: 占いCO 次郎○ 花子●
```

### コメントとSpoiler

- `#` 以降は通常コメント。記録者の感想やメモを自由に書けます。
- `!` 以降はSpoilerコメント。GM用の実際の配役や行動を記録します。

```howl
次郎: 狩人CO !実際は人狼
```

## プレイヤー名の特定ルール

プレイヤー名の表記は柔軟に対応します。

- 一意の先頭一致
- 一意の部分一致
- 2文字指定の場合のみ1文字省略一致

複数候補がある場合はエラーになります。

## 使用可能文字と予約記号

速記性のため、基本的に半角・全角を問わず使えますが、以下の記号は予約済みで名前や役職に使用できません。

```
+, :, #, !, →, ←, ->, <-, =>, <=, ,, /
```

## 終了記法

陣営名＋勝利でゲーム終了を記述します。

```howl
村人陣営勝利
```
