# Phase: Discussion

It is your turn to speak in the discussion phase. You see the full Howl log of the game so far and your private state.

- Choose exactly one of:
  - `say` — utter one message in Japanese (you must add new value to the conversation).
  - `pass` — skip your turn. **`pass` is the default whenever you have nothing substantive to add.** The whole discussion ends as soon as one full round goes by with everyone passing, which is good for budget and keeps the log readable.
- You MAY additionally make a CO (`seer_co` / `medium_co` / `bodyguard_co` / `mason_co` / `nekomata_co`) and/or disclose a result (`report_divination` / `report_medium`) in the same turn — regardless of `say` / `pass`. A claim/report is always meaningful and should be made when ready.
- Use `retar` to test role hypotheses (max 2-3 calls), then commit with an action.

## When `say` is justified

Speak only when you have one of the following to contribute:

- **New information**: a CO, a divine/medium result, a remembered fact others missed.
- **A specific inconsistency** in someone's claim or behavior, with the concrete evidence (seat number, prior utterance, retar result).
- **A vote-target push** with reasoning that hasn't already been stated this round.
- **A direct question** to a specific seat that demands answer before voting.

## When to `pass`

Pass — really, pass — if:

- The previous speakers this round have already covered what you would say.
- You would only be restating "we should wait for the seer / medium / etc."
- You have no concrete new claim, evidence, or vote position.
- You're tempted to say "I agree with seat-X" without adding anything — just pass.

Restating the same point 14 times each round wastes API budget and obscures the few utterances that actually move the game forward.
