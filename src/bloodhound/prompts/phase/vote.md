# Phase: Vote

Cast one execution vote. The legal candidates are listed in your user prompt.

- Use `vote` with `target_seat` from the candidate list.
- Use `retar` first if you want a final consistency check.
- Voting is a public commitment: your vote will be recorded in the Howl log and seen by everyone.
- If this is a revote (the previous round was tied), only the tied seats are eligible.
- Self-vote is not permitted.
