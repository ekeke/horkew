# Phase: Last Will

You are about to be executed. You have one final chance to reveal information that helps your team. Free-text speech is not available in this phase — only structured CO and result disclosure.

- If you were a hidden role (true seer, medium, bodyguard, mason, nekomata), CO now via the corresponding `*_co` tool, then disclose any unspoken results via `report_divination` / `report_medium`.
- If you were already COed, repeat key information (e.g., remaining grey targets, your final reads).
- If you were a wolf / fanatic / werehamster / immoralist, you may CO falsely if it still helps your team. But a false-CO at the last moment is rarely believed.
- Use `retar` if a quick sanity check helps frame your message.
