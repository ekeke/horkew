# アクション空間・報酬設計

実装 (`action.ts`, `reward.ts`) から独立したドメイン設計ドキュメント。

## アクション空間

### ゲームの流れとアクション

```
夜フェーズ
  └─ night: 夜行動対象 (占い/護衛)
  └─ attack_target + attacker: 襲撃 (狼チーム)

昼フェーズ
  ├─ claim:   CO宣言・結果報告
  ├─ target:  CO対象指定 (占い先、護衛先、共有相方)
  ├─ comm:    シグナル (疑い/信頼/告発/同意/反対/投票意思...)
  ├─ propose: 処刑提案 (複数候補を同時提案)
  ├─ predict: 配役予想
  ├─ leader:  指揮者応答 (follow/defy)
  └─ vote:    投票
```

### アクションマスキング

各ヘッドに対して、不正な行動を `-Infinity` でマスク:
- vote: 自分と死亡者を除外
- night: 役職に応じた有効対象のみ (占い師→生存者、狩人→自分以外)
- claim: 既にCO済みなら結果報告系のみ有効
- comm: 対象系シグナルは生存他者のみ
- attack_target: 生存者かつ非狼のみ
- attacker: 生存狼のみ

## 報酬設計

### 終端報酬 (ゲーム終了時)

| 結果 | 村陣営 | 狼陣営 | 狐陣営 |
|------|--------|--------|--------|
| 村勝 | +1.0 | -1.0 | -1.0 |
| 狼勝 | -1.0 | +1.0 | -1.0 |
| 狐勝 | -1.0 | -1.0 | +1.0 |
| 引分 | -0.5 | -0.5 | +0.3 |

### 中間報酬

| イベント | 対象 | 値 | 根拠 |
|----------|------|-----|------|
| LW(ラストウルフ)生存 | 狼陣営(werewolf, fanatic) | +0.05/日 | 縄を消費させず生存することが狼の中間目標 |
| 妖狐生存 | 狐陣営(fox, immoralist) | +0.07/日 | 生存自体が勝利条件 |

### 中間報酬の設計原則

1. **勝利条件との整合**: 報酬は陣営の勝利条件に直結する行動を強化すべき
2. **帰属の明確さ**: 「誰の行動が原因か」が曖昧な報酬は避ける
3. **スケール**: 中間報酬の累計が終端報酬 (±1.0) を圧倒しないこと
4. **負の中間報酬は慎重に**: 探索を過度に制限するリスク

### 陣営別の目的と報酬方針

#### 村陣営
- **目的**: 狼全滅 (狐がいれば先に狐排除)
- **報酬化しやすいもの**: 狼処刑、護衛成功、Hati 詰み到達
- **報酬化が難しいもの**: 「正しい推理」（投票結果でしか観測できない）
- **注意**: 味方処刑が最善手の局面もある（狐盾、引き分け進行）

#### 狼陣営
- **目的**: 生存数で村と同数以上
- **報酬化しやすいもの**: 村人処刑、噛み成功
- **報酬化が難しいもの**: 偽装の巧みさ（直接観測不可）

#### 狐陣営
- **目的**: 生存（ゲーム終了時に生きていれば勝ち）
- **報酬化しやすいもの**: 生存日数、占い回避
- **報酬化が難しいもの**: 「目立たなさ」

### 計画中の追加報酬

#### Hati 詰み報酬 (村陣営)
- 処刑後に Hati で詰み判定 → 詰み到達で村側に +X
- 将来: 詰みまでの距離に応じた傾斜報酬
- コスト: ほとんどの局面で 0ms（枝刈りで即棄却）

#### Hati 被詰み報酬 (狼陣営)
- 村に詰まされた → 狼側に -X
- 「詰まされない局面を維持する」行動を強化

### 陣営別モデル化と報酬の関係

報酬体系が陣営ごとに根本的に異なるため、モデルを陣営別に分離する構想がある:

| 陣営 | モデル | 主要報酬シグナル |
|------|--------|-----------------|
| 村 | village_net | Hati 詰み係数改善 +X (未定)、勝利 +1.0 |
| 村 | mason_net | Hati 詰み係数改善 +X (未定)、勝利 +1.0 |
| 狼 | wolf_net | LW生存 +0.05/日、勝利 +1.0 |
| 狼 | fanatic_net | LW生存 +0.05/日、勝利 +1.0 |
| 狐 | fox_net | 生存 +0.07/日、勝利 +1.0 |
| 狐 | immoralist_net | 狐の生存 +0.07/日、勝利 +1.0 |


共有モデルだと異なる報酬シグナルが干渉するため、分離により学習効率の向上が期待できる。
